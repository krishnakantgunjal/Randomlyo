# Randomlyo

Simple, fast online tools for random picks, decisions, teams, and giveaways — 
no login, no clutter.

## Tools
Random Wheel · Coin Toss · Random Name Picker · Random Number · Dice Roller · 
Giveaway/Winner Picker · Who Goes First · What Should We Eat · Random Team 
Generator · Random Game Picker · Tournament Draw · Random Group Generator · 
Yes/No

## Tech stack
Astro + Tailwind CSS, deployed on Cloudflare Pages.
